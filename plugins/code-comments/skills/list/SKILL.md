## 目的

差分の中から、追加・変更したコメントの行だけを取り出す。コードを読み飛ばして言葉だけを頭から読めるため、用語のゆれや責務の外の記述などの傾向を変更全体で見つけられる。

## 手順

1. スクリプトで一覧を作る。ユーザーが引数を指定していれば、そのまま渡す。

   ```sh
   node "${CLAUDE_SKILL_DIR}/scripts/list-comments.js" $ARGUMENTS
   ```

2. 一覧を頭から読み、注入されているコメントの原則に照らして問題のあるものを探す。docblock は変わった行だけが載るため、前後の行が必要なら元のファイルを読む。
3. 問題のあるものを 1 件ずつ、行番号・直す案・理由を添えて示す。直すかどうかはユーザーが決める。
4. 直したら一覧を作り直し、残りがないかを確かめる。

分岐元が既定のブランチでないときは、`--base` で指定する。わからなければ、ユーザーに確認する。

## オプション

| オプション | 意味 | 既定 |
|---|---|---|
| `--from REV` | 変更前の版 | `--base` との分岐点 |
| `--to REV` | 変更後の版 | 作業ツリー（未コミットと未追跡のファイルも含める） |
| `--base BRANCH` | `--from` を省略したときに分岐点を求める相手 | origin の既定のブランチ。なければ `main` |
| `-o`, `--output PATH` | 出力先。相対パスは呼び出したディレクトリが基準 | 標準出力 |

標準エラーに「ファイル数 まとまりの数」を出力する。

## 一覧の中身

- 対象の拡張子: PHP、JS・TS 系、`.tpl`、`.sql`、`.css`、`.scss`、`.html`、`.sample`。`Smarty/compile` と `.min.` を含むパスは除く。
- SQL は `--` と `/* */` に加えて `COMMENT ON` も対象にする。
- 隣り合うコメントの行は 1 つのまとまりにし、見出しを行番号にする。行番号は変更後の版のもの。
- 変更前と同じ文のままの行だけのまとまりは除く（コードだけ変わった行の後ろのコメントや、移動しただけのコメントなど）。
